## Execution order
**L0 → L1 → L2 → L3 → L4 → L5**

A failed prerequisite blocks dependent tests. No dependent PASS may be recorded from assumption.

## Evidence standard
Each executed test records:
- test ID;
- timestamp;
- environment;
- commit SHA;
- input/fixture identifier;
- observed output;
- PASS/FAIL;
- failure reason if FAIL;
- cleanup result.

## First execution target
M20.2 will execute the minimum L0 + L1 + L2 + L3 smoke path before any real-user or field pilot test.
