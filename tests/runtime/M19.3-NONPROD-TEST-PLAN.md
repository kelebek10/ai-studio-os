# M19.3 Non-Production Test Runner v1.0

This runner validates the M19 durable task/event ledger in disposable PostgreSQL only.

Required execution environment:
- PostgreSQL 16 disposable container
- no production credentials
- no production network target

Tests:
T01 schema creation
T02 canonical task creation
T03 exact replay uniqueness
T04 conflicting replay rejection
T05 invalid transition contract check
T06 sequence uniqueness/concurrency
T07 stale transition
T08 rollback + retry
T09 event immutability
T10 unauthorized direct mutation
T11 forged actor/scope
T12 provider APPROVED injection
T13 restart/recovery
T14 lineage/evidence integrity
T15 M17 non-regression

PASS requires raw output and database verification evidence for each applicable test.
