# SECURITY & INTELLIGENCE LAYER — DECISION v1.0

Decision: Adopt SENTINEL as an independent control layer.

Purpose:
Protect the PEYZAJ AI research bridge before provider execution and
challenge provider output before evidence promotion.

Authority:
SENTINEL may BLOCK or require review.
SENTINEL cannot approve Core data.
SENTINEL cannot write Core.
SENTINEL cannot grant itself authority.

Provider independence:
SENTINEL is separate from Claude, Gemini and Copilot provider teams.
Provider output is treated as untrusted input.

Initial team:
- SECURITY
- INTELLIGENCE
- REDTEAM

Conflict:
Maximum three rounds applies only to problem-solving.
Unresolved critical conflict becomes BLOCKED / Human Gate.

Deployment:
Foundation files only at this stage. No provider credentials are
enabled and no production mutation is performed.
