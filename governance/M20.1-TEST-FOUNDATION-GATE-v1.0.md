# M20.1 TEST FOUNDATION GATE v1.0

**Status:** OPEN — NON-PRODUCTION TEST FOUNDATION
**Parent:** M19.5 Non-Production Closeout
**Branch:** `phase-1-3-foundation`
**Milestone:** M20 — Test & Pilot Foundation

## Objective
Establish the first controlled test foundation for PEYZAJ AI before any pilot or real-user test.

## Boundary
- Non-production test environment only.
- No production migration, configuration mutation, or live customer data.
- M19.5 remains CLOSED; this milestone does not reopen it.
- No new agent/provider authority.
- Test results are evidence; no PASS may be declared without recorded evidence.

## M20.1 scope
1. Define test layers and execution order.
2. Define deterministic PASS/FAIL criteria.
3. Define test data classes and synthetic-data rule.
4. Define end-to-end smoke path from communication surface to controlled task result.
5. Define failure, timeout, recovery and Human Gate scenarios.
6. Define mobile-first acceptance checks.
7. Define evidence and cleanup requirements.

## Test layers
- **L0 — Integrity:** repository, branch, environment and boundary checks.
- **L1 — Control-plane smoke:** task creation, assignment, ACK, lease and audit.
- **L2 — Recovery:** expiry, recovery, re-dispatch and duplicate-execution protection.
- **L3 — End-to-end:** Telegram/n8n → gateway/orchestrator → controlled agent execution → evidence/result.
- **L4 — Domain:** landscape request, measurement, plant recommendation, irrigation, survey, cost and quote flows.
- **L5 — Mobile pilot:** phone-first interaction, latency, error visibility and recovery UX.

## Exit criteria
M20.1 is ready to close only when:
- the matrix is committed;
- every test has an owner/executor, precondition, evidence target and PASS/FAIL rule;
- required test fixtures are identified;
- production boundary checks are explicit;
- the first executable smoke suite is defined.
